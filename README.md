# FakeStore E-Commerce Website

A modern responsive e-commerce website built with Vue 3, Pinia, Vue Router, and Tailwind CSS using the FakeStore API.

## Features

* Responsive modern UI
* Dynamic product listing
* Product detail page
* Shopping cart system
* Order page
* Random featured products banner
* State management with Pinia
* SPA routing with Vue Router
* Tailwind CSS styling

---

## Technologies Used

### Frontend

* Vue 3
* Vite
* Pinia
* Vue Router
* Tailwind CSS

### API

* FakeStore API

## Installation

Clone the repository:

```bash
git clone https://github.com/Norakneath25/E-Commerce_Store.git
```

Move into project directory:

```bash
cd E-Commerce_Store
```

Install dependencies:

```bash
npm install
```

---

## Run Development Server

```bash
npm run dev
```

Then open:

```bash
http://localhost:5173
```

---

## Build for Production

```bash
npm run build
```
